📖 How to Play Skrub

🎨 How the game works

Each round, one player is the artist and gets a secret word to draw. Everyone else tries to guess it by typing in the chat. Guess fast for more points — the sooner you get it right, the more you score. The artist earns points too, based on how many players guess correctly. Play rotates so everyone gets a turn to draw.

🚪 Where to play

  • Quick Play — drops you into a public room with other players right away.
  • Create Private Room — starts a room only people with your room code can join. You control the settings as host.
  • Join with a code — got a code from a friend? Type it in and hit Join.

🎉 Playing with a group / party

Create a private room, then copy the room code (there's a Copy button right next to it) and send it to your friends. Once everyone's in the lobby, the host can adjust rounds, draw time, and word mode, then hit Start Game.

🎤 Voice chat & mic rules

  • Voice chat is optional — tap Enable Voice Chat in the lobby if you want to use it.
  • While everyone's guessing, mics are muted between guessers — no shouting out the answer!
  • The moment you guess correctly, your mic opens up in a private channel with the artist, so you two can chat while others keep guessing.
  • Each new correct guesser joins that same channel too.
  • Once the round ends, the mic opens up for everyone to chat about how it went.
  • Voice works best when your connection can reach other players directly — being on a stable Wi-Fi connection (rather than mobile data) usually makes the mic noticeably more reliable.

💡 Tips

  • You can't guess correctly with your own drawing, so relax and have fun with it!
  • Close guesses will nudge you in the right direction — keep trying.
  • Letters get revealed as time runs low if nobody's guessed yet.
